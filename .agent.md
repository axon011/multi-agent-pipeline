# .agent.md - multi-agent-pipeline

## Project Info

Multi-agent research pipeline (Planner → Researcher → Writer → Critic) that
researches a topic across arXiv / Wikipedia / GitHub / Hacker News /
DuckDuckGo and writes a cited markdown report. Orchestrated by LangGraph
(default) or CrewAI, served by FastAPI with SSE streaming.

## Key Technologies
- LangGraph (typed state graph with a conditional critic → repair edge)
- CrewAI (alternate engine)
- FastAPI + Server-Sent Events
- Pydantic v2 structured outputs (`app/structured.py`)
- LLMs: any OpenAI-compatible model (GLM-5-turbo default) or the Claude CLI
- Langfuse tracing (no-op without keys)

## Directory Structure

```
multi-agent-pipeline/
├── app/
│   ├── main.py              # FastAPI entrypoint + demo UI at /
│   ├── config.py            # LLM backend selection + model labels
│   ├── structured.py        # schema-validated LLM output, both backends
│   ├── observability.py     # Langfuse spans
│   ├── agents/              # planner, researcher, writer, critic
│   ├── graph/pipeline.py    # LangGraph engine
│   ├── crew/                # CrewAI engine + Claude CLI bridge
│   ├── tools/               # source router + search API clients
│   ├── routes/research.py   # /research and /research/stream
│   └── models/schemas.py    # Pydantic models
├── eval/                    # eval harness (python -m eval.run)
└── tests/
```

## Key Endpoints
- `POST /research/` - Generate research report (sync)
- `POST /research/stream` - Same pipeline, streamed as SSE

## How to Identify This Project
- **Keywords**: LangGraph, CrewAI, research pipeline, multi-agent, critic, citations
- **Unique feature**: self-correcting critic → repair loop with citation grounding eval
- **NOT**: This is NOT llmops-dashboard (that's React/monitoring) or rag-eval-system (that's RAG/Qdrant)
